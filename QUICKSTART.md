# Quickstart

1. Open https://oak-healthy.kim-phong619.workers.dev (or `npm run dev` locally).
2. Press **C** (or **New routine**) and type a supplement, e.g. `Vitamin D3`. Pick the suggestion to autofill time, dose and cycle.
3. On **Today**, tap ✓ to mark a dose Taken or ✕ for Skipped. Use the toast's **Undo** if you slip.
4. Optional: **Settings → Encrypted sync → Turn on sync**, then enter the key on another device to link it.
5. Optional: **Stack → Share** copies an encrypted link to your stack.
6. Install the app from the browser menu (or **Settings → Install app**) to use it offline.

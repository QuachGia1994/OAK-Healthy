# OAK Healthy — Store Listing

## App Name
OAK Healthy

## Short Description
Quản lý thực phẩm chức năng thông minh — nhắc nhở, theo dõi chu kỳ, đồng bộ đa thiết bị.

## Full Description
OAK Healthy giúp bạn quản lý lịch uống thực phẩm chức năng một cách dễ dàng:

- **Nhắc nhở thông minh** — Lịch uống tự động theo chu kỳ (liên tục, ngàyon/ngàyoff, hàng tuần)
- **Theo dõi hàng ngày** — Đánh dấu đã uống, bỏ qua, hoặc quá hạn
- **Thống kê & Biểu đồ** — Xu hướng 7/30 ngày, tỷ lệ tuân thủ
- **Đồng bộ đa thiết bị** — Realtime iOS ↔ Android qua Firebase
- **Mã hóa dữ liệu** — AES-256-GCM tùy chọn
- **Đa hồ sơ** — Quản lý cho nhiều người trong gia đình
- **Chế độ an toàn** — Backup/restore khi cần
